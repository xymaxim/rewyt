# Desktop app

## Prerequisites

Ensure the [requirements](install.md#requirements) are installed.

## Install from binaries

Pre-built binaries for different platforms are available on the GitHub [latest
release](https://github.com/xymaxim/rewyt/releases/latest) page.

| Linux                                                                                                                           | Windows                                                                                                                           | macOS                                                                                                                                 |
|---------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------|
| [x86_64](https://github.com/xymaxim/rewyt/releases/download/v{{ release_version }}/Rewyt-{{ release_version }}-linux-x86_64.zip) | [x86_64](https://github.com/xymaxim/rewyt/releases/download/v{{ release_version }}/Rewyt-{{ release_version }}-windows-x86_64.zip) | [universal](https://github.com/xymaxim/rewyt/releases/download/v{{ release_version }}/Rewyt-{{ release_version }}-macos-universal.zip) |

Download the binary for your platform and unzip it to your working directory.
