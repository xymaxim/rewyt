# Desktop app

## Prerequisites

Ensure the [requirements](install.md#requirements) are installed.

## Install from binaries

Pre-built binaries for different platforms are available on the GitHub [latest
release](https://github.com/xymaxim/rewyt/releases/latest) page.

| Linux                                                                                                                           | Windows                                                                                                                           | macOS                                                                                                                                 |
|---------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------|
| [x64](https://github.com/xymaxim/rewyt/releases/download/v{{ release }}/Rewyt-{{ release }}-linux_x64.zip) | [x64](https://github.com/xymaxim/rewyt/releases/download/v{{ release }}/Rewyt-{{ release }}-windows_x64.zip) | [universal](https://github.com/xymaxim/rewyt/releases/download/v{{ release }}/Rewyt-{{ release }}-macos_universal.zip) |

Download the binary for your platform and unzip it to your working directory.
